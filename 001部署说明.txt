镜像信息:
  名称: exhentai-manga-manager:1.6.16
  架构: x86_64
  网页端口: 10000
  数据目录: /data   漫画库目录: /library

【方式一:导入镜像(纯图形界面,推荐)】
  1. 把 docker-镜像\*.tar.gz 上传到 NAS
  2. 飞牛OS → 容器管理 → 镜像 → 导入 → 选择该文件
  3. 创建容器:
     - 端口: 10000 → 10000(网页)
     - 挂载: 数据文件夹 → /data;漫画文件夹 → /library
       (本机建议: /vol3/1000/01/01-漫画/S/数据存放 → /data,
                  /vol3/1000/01/01-漫画 → /library)
  4. 启动后浏览器访问 http://NAS的IP:10000

【方式二:docker compose 构建】
  把 exhentai-manga-manager 文件夹传到 NAS(例如 /vol1/1000/001),
  修改 docker-compose.yml 中的挂载路径后执行:
    docker compose up -d --build
  浏览器访问 http://NAS的IP:10000
